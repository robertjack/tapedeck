# tapedeck — agent notes

This repo is **phx-managed** (see the `phx` skill for the method): `system/` is the
real codebase, `src/` is generated by `phx regen` and never hand-edited. The generator
is Sonnet 5 (`phx.toml`). All work is spec-first rounds: clauses + red evals → ticket
commit → `phx regen <component> --trigger=...` → green → redeploy.

## Components

| component | owns | boundary |
|---|---|---|
| ingest | `src/ingest/`, video+meta files | `python -m ingest add|expand` — yt-dlp fetcher/lister seams; owns the id grammar and what counts as a video |
| transcribe | `src/transcribe/`, transcripts | `python -m transcribe run|from-parakeet` — transcriber seam, model labels |
| archive | `src/archive/`, archive pages | `python -m archive render` — pure render; owns the page format |
| index | `src/index/`, tapedeck.db | `python -m index reindex|update|search` — FTS5 porter |
| ask | `src/ask/` | `python -m ask run` — librarian/answerer seams, mechanical citation verification |
| cli | `src/cli/`, config.toml scaffold | the `tapedeck` executable; orchestrates the others; never re-derives their vocabulary |

## Non-negotiables

- **Evals**: `just eval <component>` / `just eval-all`. Red-first before every ticket.
- **Never touch the repo while a regen is in flight** — the sandbox treats any file
  appearing mid-attempt as a stray generator write and deletes it on rollback.
- **Deploy discipline**: after every green regen of user-facing code,
  `uv tool install --force ~/dev/personal/tapedeck` — the installed tool is a
  SNAPSHOT and does not track the repo. Then smoke-test the deployed binary from a
  neutral cwd (evals run from the checkout and cannot see packaging gaps).
- **MANUAL.md** (repo root) is durable user documentation shipped verbatim by
  `tapedeck help manual` and packaged into the wheel via pyproject force-include; an
  eval pins every surface verb to appear in it. Surface changes update it in the
  same ticket.
- Hand-editable infra: `pyproject.toml`, `justfile`, `lefthook.yml`, `MANUAL.md`,
  `README.md`. Everything under `src/` belongs to the generator.
- The user's real library is `$TAPEDECK_HOME` → `~/dev/storage/tapedeck` (exported in
  their zshrc; predates the `~/Tapedeck` default). Never scaffold or write to a
  library home in tests — evals isolate through TAPEDECK_HOME tmp dirs.
- Git identity: personal (`~/dev/personal/` rules).
